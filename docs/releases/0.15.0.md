# Tracker+ 0.15.0

**Release Date:** August 26, 2026

## Highlights

### Legacy collection links are visible again

Timeline and graph views now recover collection membership from older tracker
records whose custom fields were stored inside multiple nested envelopes. This
keeps historical data useful without changing or migrating the source records.

## Improvements

- **Predictable conflict handling:** The closest available value wins when an
  older record contains conflicting nested values.

- **Safer compatibility reads:** Nested data is handled with explicit cycle
  and depth limits, while archived records and unavailable relationship
  endpoints retain their existing safety behavior.

## Bug Fixes

- Fixed an issue where deeply nested legacy collection fields could disappear
  from normalized timeline and graph relationships.

- Fixed duplicate legacy values so they continue to produce one relationship
  instead of repeated edges.

## Known Issues

- The extension relies on a private host database schema and should be retested
  after host application upgrades.
