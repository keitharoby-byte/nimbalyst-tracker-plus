# Tracker+ 0.8.0

## Workspace-configurable dispatch evidence

- Add a declarative `dispatchEvidence` registry contract for field, exact-tag,
  tag-prefix, and normalized-relationship evidence sources.
- Keep bundled field mappings as the backward-compatible default; workspace
  mappings merge signal-by-signal and are rejected atomically when invalid.
- Include resolved evidence values and source provenance in each detailed
  dispatch receipt, and include the effective evidence-mapping fingerprint in
  the query receipt.
- Fail closed with named missing logical signals, and reject an inert
  `includeUnscoped=true` request unless policy explicitly admits an unscoped
  type.
