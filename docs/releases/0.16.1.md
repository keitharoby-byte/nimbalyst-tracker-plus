# Tracker+ 0.16.1

**Release Date:** August 26, 2026

## Highlights

### Large timeline traversals stay reliably paginated

Traversal pages now account for their complete pagination and validation
metadata before they are returned. Results that fit remain within the safe
output limit, keep the next usable node, and provide an accurate continuation
cursor for the rest of the timeline.

## Improvements

- **Clearer response-limit recovery:** Diagnostics now distinguish a single
  oversized graph entity from an oversized fixed response envelope.

- **Reliable cursor progress:** Response trimming preserves progress whenever
  the leading graph entity can fit safely.

## Bug Fixes

- Fixed a boundary case where adding final page metadata after trimming could
  make an otherwise successful traversal exceed the output limit.

## Known Issues

- The extension relies on a private host database schema and should be retested
  after host application upgrades.

Use the project's public issue tracker to report unexpected behavior.
