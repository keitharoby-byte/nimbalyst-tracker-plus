# Tracker+ 0.10.0

## Governed delivery attribution

- Keep native pull-request fields authoritative for existing same-repository
  delivery links.
- When those fields are absent, accept only an exact `Cross-repo delivery`
  declaration on the first non-empty tracker body line.
- Preserve every repository-qualified pull request in a deterministic derived
  receipt with canonical URLs and bounded validation.
- Ignore diagnostic title, tag, issue-key, comment, and commit text as
  attribution authority.
- Keep delivery evidence isolated from workflow, readiness, progress, and
  milestone rollups.

## Reader and projection updates

- Advance the normalized timeline adapter to version 4.
- Render one-to-many delivery references in the timeline inspector while
  preserving legacy singular PR fields.
- Include the query endpoint-liveness correction, native collection/release
  support, and durable body fallback completed after 0.9.1.

## Validation

- Run TypeScript, Node, and Python regression suites.
- Build and verify the production package and reader generation manifest.
- Install the extension into the running host and verify the editor and both
  backend modules.
