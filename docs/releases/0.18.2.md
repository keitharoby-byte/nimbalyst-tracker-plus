# Tracker+ 0.18.2

**Release Date:** September 13, 2026

## Highlights

### Revision evidence can be advisory

Workspace dispatch posture may now classify packet revision, revision
currentness, and QA evidence revision as advisory. Missing or mismatched
advisory evidence remains auditable in detailed receipts without excluding an
otherwise eligible row.

The bundled posture still requires all three signals. Existing workspaces keep
their current behavior unless they activate a complete, valid override.

## Bug Fixes

- Fixed valid posture overrides being rejected when revision evidence was
  classified as advisory.

- Fixed advisory revision absence and mismatch adding admission-exclusion
  reasons.

## Safety and compatibility

- QA status remains required, so a row without a configured QA PASS value is
  still excluded.

- Positive holds, supersession, hard dependencies, workflow/type, scope,
  conditional database routing, and query-wide fail-closed validation remain
  independent admission gates.

- Detailed row and query receipts retain the effective posture, values,
  trusted sources, dispositions, and posture fingerprint.
