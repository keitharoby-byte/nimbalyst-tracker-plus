# Tracker+ 0.18.1

**Release Date:** August 28, 2026

## Highlights

### Complete large dispatch results

Dispatch results that exceed one safe response can now be read across
cursor-bound pages. Eligibility and validation are completed globally first,
so paging changes only how the complete result is delivered.

### Smaller, clearer evidence responses

Each detailed dispatch receipt is returned once instead of being duplicated
inside its candidate node. This preserves the normalized node shape and leaves
more response capacity for useful evidence.

---

## New Features

- **Dispatch pagination:** Follow opaque cursors to aggregate candidates,
  receipts, exclusions, boundaries, and relationships through a terminal page.

## Improvements

- **Stable page identity:** Cursors are bound to the complete dispatch result
  and are rejected if its evidence or graph changes between requests.

- **Consistent completeness signals:** Every page aligns its cursor,
  continuation, truncation, completion, and byte-fitting fields.

## Bug Fixes

- Fixed large detailed-receipt sets failing with no supported continuation
  path and discarding the full candidate response.

- Fixed oversized terminal receipts reporting contradictory completion and
  truncation states.

## Known Issues

- Consumers must aggregate all five dispatch result streams through the final
  cursor; an intermediate page is intentionally incomplete.
