# Tracker+ 0.9.1

## Query-local validation

- Validate predicate and role-query results against selected rows plus the
  bounded membership context required by selected launches.
- Declare validation as `query-local` and include deterministic scope counts
  and a scope fingerprint in the query receipt.
- Keep selected launch lifecycle omissions, unavailable endpoints, invalid or
  duplicate memberships, and membership cycles fail-closed.
- Prevent unrelated launch containers from changing an otherwise valid query
  result.

## Revision-currentness diagnostics

- Report revision currentness as a logical signal rather than a writable field
  name.
- List the effective configured evidence sources and their constraints when
  the signal cannot be resolved.
- Identify a present near-name field as unaccepted without adding an alias or
  weakening evidence checks.
- Continue to accept a revision string only when it matches the packet revision
  or an explicit current-revision boolean when it is true.

## Validation

- Run the TypeScript, Node, and Python suites.
- Build and verify the production package.
- Install the extension into the running host and verify its registered
  editor and backend tools.
