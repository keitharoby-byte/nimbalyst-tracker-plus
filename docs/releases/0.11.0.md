# Tracker+ 0.11.0

## Configurable dispatch scope

- Define dispatch root types and implicit-root behavior in a saved query's
  versioned `scopePolicy`.
- Configure bounded relationship mechanisms by type, direction, optional role
  qualifier, and authoritative or fallback status.
- Use neutral `rootKeys` while retaining `launchKeys` as a compatibility alias.
- Preserve the existing launch and milestone behavior when `scopePolicy` is
  omitted.

## Fail-closed provenance

- Reject malformed or overlapping policies, ambiguous mechanism matches, and
  omitted roots when explicit selection is required.
- Prefer authoritative paths and consult historical fallback relationships only
  when no authoritative path reaches a selected root.
- Report resolved native roots, policy fingerprints, mechanism IDs, authority,
  and relationship evidence in dispatch receipts.
- Keep scope identity stable when a root's display key changes but its native ID
  remains the same.

## Validation

- Run TypeScript, Node, and Python regression suites.
- Build and verify the production package and reader generation manifest.
- Install the extension into the running host and verify the live reader.
