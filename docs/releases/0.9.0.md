# Tracker+ 0.9.0

## Workspace-authoritative saved queries

- Ship no active built-in saved queries.
- Treat `.nimbalyst/tracker-plus.queries.json` as the workspace's complete
  runtime saved-query inventory rather than an overlay.
- Activate no saved queries when the workspace catalog is absent or invalid.
- Reject `null` query entries and the legacy `savedQueries` registry key so
  there is only one source of query truth.
- Preserve stable query IDs by moving six neutral predicate and traversal
  templates into `examples/tracker-plus.queries.json` for copy-and-edit use.

## Generic query engine

- Preserve direct bounded predicates, standard traversals, dispatch mode, and
  generic composed root-selection plus traversal queries.
- Remove the injected `walk-ready-milestones` query and project-specific
  `walk-readiness-v1` projection.
- Do not require `walkStage`, `buildState`, comments, tags, or other optional
  repository fields for saved-query discovery or validation.
- Preserve pagination, query fingerprints, registry hashes, validation,
  truncation reporting, provenance, and fail-closed dispatch/composed behavior.

## Maintenance and validation

- Validate Tracker+ with Nimbalyst 0.72.8 and Extension SDK 0.3.0.
- Update fixable transitive development dependencies without crossing SDK or
  host major-version boundaries.
- Run the full Node, TypeScript, and Python suite, production build, package
  verification, and Nimbalyst hot reload.

Closes GitHub issue #30.
