# Tracker+ 0.8.2

## Dispatch routing and launch validation

- Honor each configured role's `attentionTags` alongside `ownerAliases` during
  dispatch pre-admission, so explicitly routed rows receive detailed receipts.
- Validate selected launch roots against their actual active
  `part-of-launch` graph before candidate admission.
- Keep validation-only non-dispatch members out of candidate nodes, edges, and
  detailed row receipts.
- Preserve terminal fail-closed behavior for missing evidence, unresolved or
  archived membership endpoints, incomplete launch lifecycle fields, cycles,
  validation findings, and response truncation.
- Continue withholding candidates, totals, and launch rollups whenever a
  terminal condition prevents a trustworthy Dispatch receipt.

## Validation

- Regression coverage for attention-tag routing and zero-candidate launches.
- Regression coverage for unresolved membership endpoints and incomplete
  lifecycle fields.
- Full TypeScript, Node, and Python test suite.
- Production extension build, package verification, and Nimbalyst hot reload.
