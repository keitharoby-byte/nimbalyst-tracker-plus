# Tracker+ 0.18.0

**Release Date:** August 27, 2026

## Highlights

### More resilient native queries

Native-reader deadlines now adapt to the kind and bounded size of each
request. If a request exceeds its deadline, it fails without partial data and
the next request starts with a clean helper instead of inheriting stale state.

### Dispatch policy that matches workspace operations

Workspace configuration can now declare supported dispatch signals as
required, conditional, positive blockers, or advisory. Revision and QA gates
remain mandatory, while every decision retains exact source and disposition
evidence in its receipt.

---

## New Features

- **Configurable dispatch posture:** Apply a validated, versioned admission
  posture without rebuilding the extension.

- **Conditional database routing:** Require route approval only when an
  explicit database-bearing signal is true.

## Improvements

- **Right-sized query deadlines:** Larger bounded pages and graph traversals
  receive proportionate execution time while all deadlines remain capped.

- **Auditable advisory signals:** Receipts preserve advisory values, trusted
  sources, active conditions, dispositions, and a stable policy fingerprint.

## Bug Fixes

- Fixed valid cold-start and concurrent reader requests failing under a single
  fixed deadline regardless of their bounded workload.

- Fixed timed-out helper cleanup affecting the immediately following request.

## Known Issues

- The native reader depends on the packaged host's private SQLite schema and
  should be retested after host upgrades.
