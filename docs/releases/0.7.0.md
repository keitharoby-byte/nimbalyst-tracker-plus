# Tracker+ 0.7.0

Release date: August 2, 2026

## Highlights

### Configure richer queries without rebuilding

Installers can now define composed saved queries that select roots and expand
their typed relationship evidence in one bounded call. Predicate, traversal,
and composed templates are managed through the external workspace query
catalog.

### Trust readiness and dispatch results at larger scale

Walk readiness is explicit about its native inputs and supporting relationship
evidence, and missing proof remains unknown. Dispatch scans now summarize early
policy exclusions before building detailed receipts, keeping ordinary large
workspaces within the safe response envelope.

## New features

- Added evidence-backed walk readiness with predecessor, blocking condition,
  blocking owner, runtime availability, and stored-versus-derived provenance.
- Added installer-managed composed saved queries to
  `.nimbalyst/tracker-plus.queries.json`.

## Improvements

- Large dispatch scans retain auditable admission totals, reason counts, and a
  stable fingerprint without returning a full detailed receipt for every
  obviously out-of-scope row.
- Terminal walk roots are authoritative, while nonterminal roots use one
  consistent readiness fraction and percentage.
- Role-distinct relationship edges continue to remain separate throughout
  normalization and traversal.

## Bug fixes

- Fixed saved role queries that could fail when a matching item also contained
  legacy relationship fields.
- Fixed multi-launch dispatch queries that could exceed the response envelope
  before returning an otherwise complete result.

## Known issues

- Tracker+ reads a host-managed SQLite schema. Revalidate compatibility after
  upgrading Nimbalyst.
