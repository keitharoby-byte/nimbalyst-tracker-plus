# Tracker+ 0.14.0

**Release Date:** August 26, 2026

## Highlights

### Reliable pagination signals

Agents and integrations can now determine whether another query or traversal
page exists from one consistent contract. `hasMore`, `continuationRequired`,
and `nextCursor` agree on every page shape, including size-trimmed responses.

### Historical collection data stays historical

Archived work no longer contributes active inline collection relationships.
Current release and milestone dispatch scopes continue normally even when old
items retain their former collection value.

## Improvements

- **Safer completeness checks:** Empty, terminal, composed, dispatch, and paged
  traversal responses all expose the same boolean completion signal.
- **Preserved fail-close behavior:** Explicit active relationships with missing
  endpoints still stop selection instead of being silently ignored.

## Bug Fixes

- Fixed query and traversal responses that omitted `page.hasMore`.
- Fixed archived inline collection membership blocking current authoritative
  dispatch selection.

## Known Issues

- The read adapter depends on the host's private local schema and should be
  revalidated after host upgrades.
