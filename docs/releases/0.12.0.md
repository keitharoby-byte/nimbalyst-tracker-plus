# Tracker+ 0.12.0

## Selectable unresolved-evidence disposition

- Honor `failOn.unresolvedEvidence: false` for dispatch saved queries.
- Exclude only rows with incomplete required evidence while returning
  independently complete candidates and trustworthy totals.
- Preserve query-wide `DISPATCH_EVIDENCE_INCOMPLETE` behavior when the setting
  is omitted or `true`.

## Auditable safeguards

- Add evidence-completeness state and missing-signal details to every detailed
  dispatch receipt.
- Report whether unresolved evidence is terminal or row-excluding in the query
  receipt.
- Accept only JSON booleans for dispatch failure controls.
- Keep graph integrity, validation, warnings, topology, and truncation
  fail-closed.

## Validation

- Exercise mixed complete and incomplete candidates in both policy modes.
- Verify deterministic receipts, candidate ordering, totals, and fingerprints.
- Run the full source, package, and installed-host validation workflow.
