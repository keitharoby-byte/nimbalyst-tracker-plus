# Tracker+ 0.13.0

## Root-aware timeline projection

- Use active incoming `part-of-launch` membership for launch roots.
- Use active incoming `in-collection` membership for milestone and release
  roots.
- Include every eligible relationship whose endpoints are both emitted while
  retaining one-hop boundary limits.

## Auditable summaries

- Summarize every emitted direct milestone member of a release.
- Reconcile normalized source, eligible, emitted, and excluded relationship
  counts in the projection receipt.
- Report contract exclusions by count and relationship type.
- Keep unknown relationship types fail-closed with a named diagnostic.

## Validation

- Verify a milestone member's `implements` edge survives rooted sync.
- Verify a release with ten milestone members reports all ten summaries.
- Verify relationship counts reconcile deterministically.
- Preserve launch membership, nested boundary, pagination, selector, and
  no-selector behavior.

Closes GitHub issue #41.
