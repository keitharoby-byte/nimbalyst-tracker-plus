# Tracker+ 0.17.0

**Release Date:** August 27, 2026

## Highlights

### Find work by packet identifier

Queries can now select tracker items by their packet identifier, making it
easier to locate one packet, retrieve a bounded set, or find items that have a
packet assignment. Matching identifiers are also visible on returned items.

## New Features

- **Packet-aware queries:** Use exact, list, or presence predicates with packet
  identifiers in item queries and traversal member filters.

## Improvements

- **Consistent identifier matching:** Packet identifiers use safe,
  case-insensitive matching consistent with other tracker identifiers.

## Known Issues

- The extension relies on a private host database schema and should be retested
  after host application upgrades.

## Feedback

Use the project's public issue tracker to report unexpected behavior.
