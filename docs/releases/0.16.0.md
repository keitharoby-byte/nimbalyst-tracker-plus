# Tracker+ 0.16.0

**Release Date:** August 26, 2026

## Highlights

### Deeper historical timelines work by default

Timeline and report generation now reads substantially deeper legacy custom
field envelopes before asking for intervention. For unusually deep records,
each call can select a larger safe bound without expanding the relationship
graph or changing source data.

### Parameter errors explain the correction

All six tools now attach concise usage guidance to incomplete, conflicting,
cursor-invalid, over-complex, and nesting-limit errors. The response identifies
the affected tool, relevant constraints, and a valid generic example.

## Improvements

- **Configurable compatibility depth:** Timeline, report, query, and traversal
  calls accept a bounded legacy-depth setting and echo the effective value in
  their receipts.

- **Clearer safety boundaries:** Storage-envelope depth is explicitly separate
  from relationship traversal depth, preventing accidental graph expansion.

## Bug Fixes

- Fixed valid historical timelines failing at the previous shallow default.

- Fixed parameter errors that identified a problem without showing the
  correct call shape.

## Known Issues

- The extension relies on a private host database schema and should be retested
  after host application upgrades.
