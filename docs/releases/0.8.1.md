# Tracker+ 0.8.1

## Complete query and traversal retrieval

- Make predicate-query completeness explicit with `resultsComplete`,
  `continuationRequired`, and `responseTruncated` page fields.
- Require agents to follow opaque predicate cursors automatically until the
  complete result is aggregated, unless the user requested only one page.
- Add opt-in cursor pagination for standard graph traversals so node and edge
  caps become safe page sizes instead of a terminal result ceiling.
- Bind traversal cursors to the selected node and edge identities, rejecting a
  continuation if the graph changes between pages.
- Keep dispatch and composed traversals atomic and fail closed because partial
  candidate or evidence sets are not safe to interpret.

## Timeline validation corrections

- Keep active typed `part-of-launch` relationships as the sole launch
  membership and rollup authority; legacy launch-key tags no longer make valid
  native projections non-PASS.
- Preserve nested-lane `timeline-item` rows as boundary context in launch-rooted
  snapshots without promoting them to direct launch membership.

## Validation

- Full TypeScript, Node, and Python test suite.
- Production extension build and package verification.
- Hot reload into Nimbalyst with four read/query tools, two projection tools,
  and the Tracker Timeline custom editor loaded.
